# Code of Conduct

Be respectful and constructive. Harassment, discrimination, personal attacks, and unwelcome sexual attention are not acceptable in issues, pull requests, or discussions.

Maintainers may edit, remove, or reject contributions that don't follow this code, and may restrict participation for repeated violations. Report concerns by opening a private security advisory or contacting the maintainer listed on the repository profile.

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
